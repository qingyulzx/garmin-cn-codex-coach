# 测试版隐私说明

本项目是运行在使用者电脑上的社区软件，不运营账号中转服务器。

## 登录

账号、密码和验证码在本机输入，用于向 Garmin 完成认证。密码不写入脚本、配置文件或项目日志。成功登录后的令牌保存在个人应用数据目录，它可以代表你的登录会话，因此不要上传或分享。Windows 登录脚本会限制该目录的继承访问权限；这不能防御已经控制你电脑的程序或管理员。

## AI 分析

MCP 工具按 Codex 请求读取 Garmin 数据。返回的运动、睡眠或健康信息会进入 Codex 会话并用于模型处理；这不是离线 AI。请了解 Garmin、Codex / OpenAI 各自的数据政策与账户设置。

不要求分享精确轨迹；默认工具选择以活动汇总、分圈和训练摘要为主。某些上游返回值可能带有位置、个人资料或其他字段，数据最小化仍需使用者与客户端配合。本版本尚未对上游所有返回字段实施统一脱敏。

## 存储与移除

程序默认保存登录令牌，不自动建立个人训练数据库或定时日志。个人档案只在使用者要求保存时创建，并应保存在应用数据目录。移除 MCP 配置可停止通过该服务器查询；删除令牌目录可清除本机保存的登录会话。已经进入 Codex 会话的数据需要按 Codex 的会话管理方式处理。

## 问题反馈

GitHub Issue 属于公开空间。不要贴账号、密码、验证码、令牌、完整健康记录或带精确位置的活动文件。提交问题只需软件版本、操作系统、发生步骤和脱敏的错误类别。
