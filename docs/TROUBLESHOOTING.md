# 常见问题

## 没有 Python 3.12

`garminconnect 0.3.17` 要求 Python 3.12 或更新版本。安装 Windows Python，并保留 Tcl/Tk 组件，再运行 `01-install.cmd`。测试版不自动下载解释器或修改系统 PATH。

## 安装依赖失败

检查网络是否能访问 PyPI。代理环境可能影响安装；不要把含账号密码的代理地址贴到 Issue。安装失败可重新运行 `01-install.cmd`。

## 登录失败或需要验证码

确认账号属于 `connect.garmin.cn`。国际区账号不适用于本测试版。密码区分大小写，末尾空格会原样保留；可在本机勾选显示密码核对。

验证码在单独窗口输入。遇到连接中断、SSL、JWT 或频繁登录导致的限流时，不能仅凭报错判断密码错误。停止反复尝试，稍候重试，并检查本机网络。可以在终端运行 `02-login.cmd --force-reauth` 主动重新认证。

本程序只显示错误类别以减少隐私泄露。如果仍无法连接，反馈错误类别和步骤；不要提交账号、密码、验证码或令牌。Garmin 更新接口后，可能需要发布新的兼容版本。

## Codex 中没有工具

先运行 `03-connect-codex.cmd`，然后完全退出并重新打开 Codex。运行 `04-check.cmd` 检查工具注册，它不验证账号登录。实际数据调用若提示尚未登录，运行 `02-login.cmd`。

如果企业或学校管理策略禁止本地 MCP，需要按该客户端的管理策略处理；本程序不会绕过这些限制。

## 同名配置冲突

项目使用独立名称 `garmin_cn_coach`。如果旧安装已经用这个名称，脚本不会覆盖其他路径。在 Codex 设置里先移除旧项，再对希望保留的安装运行配置脚本。已有 `garmin_cn` 不会被替换。

## 缺少某些指标

工具存在不代表账号或设备一定有该指标。佳明设备型号、权限、数据类型和接口状态都会影响结果。没有乳酸阈数据不应自动用手表默认心率分区替代。

## 上传或同步到哪里

本版仅提供数据读取。不会删除、修改活动，也不会上传训练课表。GitHub 下载或解压不会自动登录 Garmin；每位使用者需在自己的电脑上认证。
