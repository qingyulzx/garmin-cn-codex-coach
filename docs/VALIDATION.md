Windows PowerShell 安装脚本、29 个公开 Python 源文件和教练 Skill 格式检查通过。以上检查日期：2026-10-05。

`scripts/check_mcp.py` 会验证 Python 依赖、中国区认证端点、协议初始化和工具名单。它不会访问训练数据；“检查通过”不是“账号登录成功”。

没有完成多用户、多个 Garmin 设备、所有代理环境或跨平台验证。没有验证新安装用户的所有真实登录分支。Windows 安装流程依赖已有 Python 3.12+ 和正常的 PyPI 访问。发布为预发行测试版，遇到问题请按脱敏反馈流程报告。
